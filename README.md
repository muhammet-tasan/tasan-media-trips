# TASAN MEDIA Trips

YouTube trip videos with DJI Pocket 3 footage, German voice-over, and Remotion-powered motion graphics.

## Workflow
1. Manual editing in CapCut (DJI Pocket 3 footage)
2. German voice-over recording
3. Remotion/React supporting B-roll and motion graphics
4. Final editing back in CapCut

## Project Structure
