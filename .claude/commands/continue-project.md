# /continue-project

Resume from PROJECT_STATUS.md and offer direction on next work.

## Process
1. Read PROJECT_STATUS.md and CLAUDE.md
2. Summarize current project phase (1-2 sentences)
3. List pending work from the status document
4. Ask: "What would you like to work on next?"
5. Wait for user direction before starting implementation

## Key Principle
**No automatic start.** Always ask before implementing, ensuring intentional resumption.

```

**Phase:** [e.g., "Remotion workspace setup"]

- [item]

**What's pending:**
- [item]

**What would you like to work on next?**
```

Offer specific suggestions from PROJECT_STATUS.md next steps, but respect user direction.
