# /my-project-status

Summarize current project phase, completed work, and next steps.

## Process
1. Read PROJECT_STATUS.md in full
2. Summarize the project status in one paragraph (125 chars max)
3. Inventory completed vs. pending items for the current video
4. Highlight any blockers or decisions needed
5. Recommend next steps based on status document

## Output Format
```
## Current Status
[One paragraph summary, ≤125 characters]

## Progress on Mulhouse Automobile Museum
✓ Completed:
- [item]

○ Pending:
- [item]

## Blockers / Decisions Needed
- [item or "None"]

## Recommended Next Steps
1. [highest priority]
2. [secondary priority]
```

After displaying status, ask: "Soll ich loslegen?" (Should I get started?) to confirm next work.
